# Changelog

All notable changes. The API follows [semantic versioning](https://semver.org).
Generated schemas, schema IDs, the file store layout and the wire format of
framed payloads do not change between versions unless an entry says so.

## Unreleased

Breaking. Schemas generated for the same types are unchanged: same bytes,
same IDs. Stored file names change (see below).

### Changed

- The package is `structavro` (was `avro`).
- Requires `github.com/ln80/struct-sensitive` v0.9.0. A sensitive tag that
  does not parse fails schema generation with `ErrInvalidTag`.
- `registry.New` and `Setup` are replaced by `registry.Open(ctx, store,
  opts...)` with `WithCurrent`, `WithReaderSchema` (was `ReadOnly`),
  `WithPersistCurrent`, `WithAPI` and `WithWireFormatter`. A store's
  `Persister`, `Walker` and `WireFormatter` are detected. `GetCurrent` and
  `SchemaIDGetter` are removed; use `Current` and `EncodeWithID`.
- `tool.JobExecuter.EmbedSchemas(walker, cfg)` no longer takes a persister:
  it copies the schema versions into `cfg.Out` itself.
- The generated embed accessor is `embed.go` (was `init.go`). A generated
  `init.go` is removed.
- Generated files start with `// Code generated by struct-avro. DO NOT EDIT.`
  and have goimports-style imports.
- `BuildEnvelopeSchema` registers the record entries on the API.
- `NewAPI` bounds decoder allocations; see `WithMaxSliceAllocSize` and
  `WithMaxByteSliceSize`.
- **File names.** `fs.Adapter` writes `<namespace>/0001@<id>.json`: the
  version is zero-padded to 4 digits so that names sort in version order.
  Unpadded names (`1@<id>.json`) are still read. Persisting a stored version
  again, which `EmbedSchemas` does, renames its unpadded file after checking
  that it holds the same schema. Schema IDs and contents do not change.
- `fs.Adapter` validates schema IDs (16 lowercase hex characters) and file
  names, never overwrites a stored version, and returns the existing ID when a
  stored schema is persisted again.

### Added

- `FieldAnnotator`, `SensitiveTags`, `NoAnnotations`,
  `EnvelopeConfig.Annotator` and `WithFieldAnnotator`: annotate fields from
  any tag.
- `EnvelopeConfig.Fingerprint`: names of the fingerprint fields.
- `Registry.Encode`, `EncodeBatch`, `EncodeWithID`, `Decode`, `DecodeBatch`.
- `RegisterEntries`, `ErrInvalidTag`, `ErrInvalidConfig`,
  `registry.ErrInvalidSchema`, `registry.ErrNoCurrentSchema`.
- `registrytest`: a conformance suite for schema stores.

### Removed

- `WithRoot`, `WithEvent`, `WithCache`, `WithAccumulator`, `WithInject`,
  `Cache`, `Accumulator`, `Config` and `TagOptions`.

### Fixed

- Code generation wrote no schema files to `Out` when it differed from the
  store, so the generated package did not compile.
- A corrupt or non-record schema from a store panicked the registry.
- A schema ID read from a payload was used in a file glob unchecked.
- `Persist` could truncate a stored version on a failed write.
